# Retired slide decks

## standard_model_internal.tex (retired May 17, 2026)

An earlier internal-audience deck, maintained in parallel with
`standard_model_external.tex`. Became too much to maintain; retired.

## standard_model.tex.original (retired May 18, 2026)

The hand-written Beamer LaTeX deck, renamed from
`standard_model_external.tex` on May 17. Replaced by the Quarto port
`outputs/slides/standard_model.qmd` on May 18 to give Mike a friendlier
Markdown source to edit.

The current canonical deck source is `outputs/slides/standard_model.qmd`
(builds to `standard_model.pdf` via `quarto render`).

The retired file is preserved here as a reference if the Quarto port
needs to be cross-checked against the original layout. The Quarto build
produces the same 48-page deck with the same content, though paragraph
spacing differs slightly (Pandoc/Quarto adds more space between blocks
than the original `\par` boundaries did).
