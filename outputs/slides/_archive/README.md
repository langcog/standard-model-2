# Retired slide infrastructure

Archived 2026-05-23. The Quarto + Beamer build path has been retired
because Mike edits the PowerPoint directly now; the round-trip through
.qmd was too clunky.

**Current source of truth**: `../standard_model_pptx.pptx` (and its
rendered PDF `../standard_model_pptx.pdf`).

| File | Was |
|---|---|
| `standard_model.qmd` | Quarto source for the original Beamer deck. |
| `standard_model.tex` | Beamer source generated by `quarto render --to beamer`. |
| `standard_model.pdf` | Beamer-rendered PDF. The PPTX version (`standard_model_pptx.pdf`) supersedes this. |
| `standard_model_pptx.qmd` | Intermediate `.qmd` generated by `build_pptx.py` for the PPTX render path. |
| `_preamble.tex` | Beamer LaTeX preamble (custom commands, colors, TikZ libraries). |
| `build_pptx.py` | Preprocessor that baked custom LaTeX commands and TikZ figures into PNGs, then handed off to Quarto's `pptx` format. |
| `tikz_pngs/` | Pre-rendered TikZ figures from the build_pptx pipeline. |
| `irt.pdf` | The PDF version of the IRT illustration; the deck now uses `../irt.png` (converted by the build script). |
| `m_best_explainer.tex` | Standalone TeX file for an explainer figure that didn't make it into the deck. |

Kept in `../` (still active):

- `standard_model_pptx.pptx` — **the live deck**, edited directly.
- `standard_model_pptx.pdf` — printable reference rendering.
- `irt.png` — used by deck.
- `kachergis_buckets.png` — used by deck.
- `retired/` — older retired versions, predating this `_archive/`.
